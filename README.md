This is a simple QR code generator code.
It was made during TinkerHack, a hackathon conducted by the tech community, Tinkerhub exclusively for women.
Our team consisted of three members.
We split the project into three sections:
  -The generation logic(Backend)
  -The front end.
  -Testing and deployment.

It works by converting the text entered by user into QR code. This was carried out by converting the text into bytes and then into binary.
The library qrcodejs was used for further processing.
